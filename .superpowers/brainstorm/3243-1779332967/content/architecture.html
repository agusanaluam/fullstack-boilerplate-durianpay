System Architecture

4-service Docker Compose stack

Frontend :3000

Vue 3 + TypeScript

  • shadcn-vue + Tailwind
  • Pinia (auth + payments state)
  • @hey-api/openapi-ts client
  • Vue Router (protected routes)
→
Backend :8080

Go + Chi Router

  • oapi-codegen ServerInterface
  • handler → usecase → repository
  • JWT auth middleware
  • Redis cache on payments
→
MongoDB :27017

Collections

  • users — email, password_hash, role
  • payments — id, merchant, amount, status, created_at
Redis :6379

Cache

  • Key: payments:{status}:{sort}
  • TTL: 60s
  • GET /payments hits cache first
Docker Compose services: mongodb · redis · backend (depends_on: mongodb, redis) · frontend (depends_on: backend)
